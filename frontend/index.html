How to read this chart

Swing Highs & Lows

The foundational pivot points everything else is built from. A swing high (down arrow, above the candle) is a candle whose high is the highest among several candles on either side of it. A swing low (up arrow, below the candle) is the mirror opposite — the lowest low among its neighbours. The Swing box in the top bar controls how many neighbouring candles count: lower = more (noisier) pivots, higher = fewer, cleaner ones.

BOS / CHoCH

Break of Structure (BOS) — price breaks past a prior swing point in the direction the trend was already moving. Read as confirmation the current trend is continuing.

Change of Character (CHoCH) — price breaks a prior swing point in the opposite direction to the trend. Read as an early warning the trend may be reversing.

Fair Value Gaps (FVG)

A 3-candle imbalance — a gap between candle 1's high/low and candle 3's low/high that candle 2 never traded through. Price often revisits these gaps later ("fills" them). Solid-coloured box = still open; faded box = already filled by a later candle.

Order Blocks

A candle (or small range) flagged as likely institutional positioning right before a strong move away from it. Box opacity roughly tracks a "strength" score. Note: Deriv synthetic indices have no real trading volume, so that score is calculated from candle range/body size as a stand-in — treat it as a relative signal, not literal order flow data.

Liquidity

Clusters of roughly equal highs or lows — the kind of level where many traders' stop-losses tend to cluster. Dashed line = still active; faded line labeled "LQ swept" = price has already run through it, which some traders read as a deliberate stop-hunt before a reversal.

Adjusting sensitivity

Swing — candles counted on each side of a point to call it a swing high/low. Liq % — how close two highs/lows need to be (as a percentage) to count as the same liquidity cluster: lower = stricter, higher = looser.
